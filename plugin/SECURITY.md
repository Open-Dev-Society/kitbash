# Security Policy

This plugin is part of [kitbash](https://github.com/Open-Dev-Society/kitbash). Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/Open-Dev-Society/kitbash/security/advisories/new) or email **opendevsociety@gmail.com** — not through a public issue.

The full policy, including supported versions and what the server touches, is in [SECURITY.md](../SECURITY.md) at the repository root.
